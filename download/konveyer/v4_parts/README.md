# RUVSON_QUANTUM_v4 — файл в репозитории частями

`RUVSON_QUANTUM_v4.html` (219 400 082 байт) не может лежать в git одним
блобом — лимит GitHub 100 МБ на файл. Поэтому файл разрезан на 3 части
(по ~73 МБ) и собирается обратно одной командой.

## Собрать

```bash
cd download/konveyer/v4_parts
python3 assemble_v4.py          # собирает + сверяет SHA256 каждой части и итога
# или без Python:
cat RUVSON_QUANTUM_v4.part1of3 RUVSON_QUANTUM_v4.part2of3 \
    RUVSON_QUANTUM_v4.part3of3 > RUVSON_QUANTUM_v4.html
```

## Пломбы (SHA256)

См. `SHA256SUMS`. Итог: `bd384d5b684216a67ffd9d1a26c64548f757fa68432328ca4251fe27b1b8391d`,
md5 `706b80616d326557a3c811d061bcfe40` — совпадает с asset'ом релиза
[`quantum-v4`](https://github.com/rtynbirf/ruvson-lyrics/releases/tag/quantum-v4)
(файлы идентичны байт-в-байт; asset приватного репо качается только
залогиненным пользователем — прямая ссылка без входа даёт 404).

## Что внутри

Мой плеер QUANTUM (мой дизайн и структура страницы) + все 107 треков
автора (звук + текст дословно): 84 трека играют (68 полных + 16 превью
30 с), 23 молчат (список в `../молчащие-треки-v4.json` — звука нет ни в
монолите автора, ни в доме). Веди себя с частями как с бинарём:
`.gitattributes` отключает пере-обзоры переводов строк (`-text`).
