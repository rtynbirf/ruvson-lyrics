# RUVSON_QUANTUM_v5 — файл в репозитории частями

`RUVSON_QUANTUM_v5.html` (446 710 179 байт) не может лежать в git одним
блобом — лимит GitHub 100 МБ на файл. Файл разрезан на 5 частей
(по ~89 МБ) и собирается обратно одной командой.

## Собрать

```bash
cd download/konveyer/v5_parts
python3 assemble_v5.py          # собирает + сверяет SHA256 каждой части и итога
# или без Python:
cat RUVSON_QUANTUM_v5.part{1,2,3,4,5}of5 > RUVSON_QUANTUM_v5.html
```

## Пломбы (SHA256)

См. `SHA256SUMS`. Итог: `7cddb666c7d9dcd63d92eb76e6010f9e26757ed665ec54cfde97075c15b46a4d`
— совпадает с asset'ом релиза
[`quantum-v5`](https://github.com/rtynbirf/ruvson-lyrics/releases/tag/quantum-v5)
(файлы идентичны байт-в-байт; asset приватного репо качается только
залогиненным пользователем — прямая ссылка без входа даёт 404).
