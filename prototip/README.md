# прототип СЦЕНА v0.2 — КАРАОКЕ МЕЧТЫ 2.0

Один рабочий прототип по канону «Скачал — открыл — поёшь»: без сборщика,
без зависимостей, без сети. Доноры из дома СИНГУЛЯР + свои ядра + реальные
минусы RUVSON из чистого минус-фонда СИНГУЛЯРА.

**Волна №33 — конвейер 5/5:** все пять чистовиков корпуса (№1–5) с
реальными минусами (забраны байт-в-байт из `singulyar/minus/чистый-минус/`,
git-blob SHA сверены). Выбор песни — селектор в пульте или адрес
`?song=n01…n05`; состояние (коридор, тап-метки, журнал, дубли) —
у каждой песни своё.

## Что умеет (всё живьём)

- **Реальные минусы** — `minus/<youtube-id>.mp3` (5 шт., ~30 МБ, mp3
  320k/48k): №1–5 (RUVSON) из фонда `singulyar/minus/чистый-минус/`
  (htdemucs two-stems, убран только вокал). Тексты — ЧИСТОВИК из `download/`.
- **Подсветка строк** — донор `lrc-core/0.1` (`__ЛРЦ`) разбирает
  `minus/nNN.lrc`; отсчёт, «прошлая/текущая/следующая», aria-live.
- **Транспонирование ±12 с сохранением темпа** — шифтер: `playbackRate =
  2^(n/12)` двигает тон, донор `wsola-core/0.1` (`__ВСОЛА`) тянет сэмплы
  обратно с коэффициентом `1/скорость` — длительность восстанавливается,
  темп стоит. Живая проба: 160.7 сек минуса пересобираются в браузере
  (~14 сек на среднем железе), длительность байт-в-байт та же.
- **Кривая тона в реальном времени** — своё `питч-ядро/0.1` (`__ПИТЧ`):
  YIN (разностная функция + CMND + параболическая интерполяция),
  герц 70–1100, честный null на тишине/шуме.
- **Счёт двух режимов** — своё `счёт-ядро/0.1` (`__СЧЁТ`):
  «Дружелюбный» — щадящая вогнутая кривая (sqrt-семейство);
  «Судья» — сырые числа, строгий порог ясности 0.70, штраф за девиацию
  от эталонной медианы строки (полутон = 14 баллов, потолок 40).
- **Зелёный коридор** (канон ТЗ дословно): удача (друг ≥ 75 **и** суд ≥ 65)
  кладёт полшага в копилку; вторая удачная подряд сужает коридор на
  полутон **к оригиналу** (0) и пересобирает поле WSOLA-ом;
  провал сжигает копилку; пройденные полутоны копятся в `отвоёвано`
  и не отбираются никогда.
- **Запись дублей в OPFS** — донор `opfs-core/0.1` (`__ОПФС`): без
  вытеснения, ид `<песня>-take-<N>.webm` (ASCII-закон дона), слушать/стереть,
  лучший дубль (по Дружелюбному) становится эталоном Судьи.
- **Профиль вектора** — Δv: отвоёванные полутоны, кривая роста попыток
  (спарклайн), журнал последних 10 попыток.
- **Синхро** — тап-разметка строк («Синхро: строка сейчас»), сброс,
  сдвиг меток ±3000 мс, экспорт `.lrc` через донорную обратную сборку.

## Запуск

```bash
# из корня репозитория (микрофону нужен localhost или https)
python3 -m http.server 8000
# открыть http://localhost:8000/prototip/
```

Клик «Петь» — жест пользователя: запуск минуса, микрофона и записи.
Офлайн: после первого открытия сервис-воркер держит дом в кэше
(`prototip-scena-v2`, все пять минусов; любой такт поднимает
поколение — канон СИНГУЛЯРА).

## Архитектура: комод (ящики → мост → вещи)

| Ящик | Мост | Донор/свой | Закон |
|---|---|---|---|
| `js/lrc-core.js` | `__ЛРЦ` | **донор СИНГУЛЯР**, М9, байт-в-байт | 0 сети, 0 часов, вход не мутируется |
| `js/wsola-core.js` | `__ВСОЛА` | **донор СИНГУЛЯР**, Виток 1 | детерминизм байт-в-байт |
| `js/opfs-core.js` | `__ОПФС` | **донор СИНГУЛЯР**, ПВ1 | 0 записей без явного вызова |
| `js/pitch-core.js` | `__ПИТЧ` | свой, в каноне доноров | честные русские отказы |
| `js/score-core.js` | `__СЧЁТ` | свой, канон ТЗ | 0 DOM — считается в node |
| `js/song.js` | `__ПЕСНЯ` | свой | тензорное поле песни (текст) |
| `js/stage-core.js` | `__СЦЕНА` | свой | мост `delete`+`defineProperty` |
| `js/app.js` | — | дирижёр | 0 innerHTML, 0 eval, aria |

DOM — только `createElement`/`textContent`; CSP строгий (`script-src 'self'`,
без `unsafe-inline`); в `<head>` ни строчки вне комментариев (шрам
v10.54 СИНГУЛЯРА учтён); фокус видим, `prefers-reduced-motion` уважен.

## Пробы (канон М9: «донор не мержится целиком — каждый узел с тестами»)

```bash
# node 24 каталог не принимает — прогон пофайлово (канон РИТУАЛА)
node --test tests/test_lrc_port.mjs      # 4/4: разбор нашей лирки, roundtrip, отказы
node --test tests/test_wsola_probe.mjs   # 4/4: длительность ×2, высота стоит, детерминизм
node --test tests/test_score_core.mjs    # 8/8: метрики, девиация, коридор по канону
```

16/16 зелёных. Живая поверка ЭП-06: сцена собирается, все шесть ящиков
на мосту, WSOLA-сборка −1/+1 полутон на реальном минусе, подсветка строк
работает. На headless-стенде `suspended AudioContext` — не баг дома
(канон РИТУАЛА): в живом браузере `пустить()` идёт из клика «Петь».

## Честные границы v0.2

- Моно-сведение минуса (экономит память WSOLA-сборки; стерео — следующий такт).
- `собрать()` строит поле в главном потоке (~14 сек на 2:41 минуса) —
  статус показывает «Поле строится…»; AudioWorklet/WASM — честный хвост.
- Эталон Судьи — медианы строк лучшего дубля (профиль вектора), не студийная
  мелодия: судья ждёт второй попытки, пока эталона нет — это честно.
- Мини-ритуал такта (досье → патчер → пробы → живая поверка → журнал)
  взят у СИНГУЛЯРА в урезанном составе; полный — когда дом вырастет.
