## 3. Определения модели МГ (генетическая модель)

О1. **Состояние генезиса** Ξ = (C, T, Σ, H): конфигурации, допустимые переходы, язык структурных различений, история. История входит в состояние — требование рекуррентности строки 215 (H как аргумент) сведено к памяти носителя.

О2. **Возникновение** (оператор 𝒱): 𝒱_Ξ(Ξ) := { (c, c′) ∈ T : c′ ≇_Σ c } — реализация переходов, порождающих структурно новую конфигурацию. Фильтр новизны — прямое следствие А4 («становление — не повторение неизменного»); без фильтра получается широкий v0.5-оператор E, из которого МГ выделяет порождающую часть.

О3. **Взаимодействие** (оператор 𝒲): 𝒲_Ξ(P) — связывание возникшего P с носителями через отношения R, которые сами исторически обусловлены (R = R(H)): «порождение определённостей через исторически обусловленные отношения различий» (строка 265). Взаимодействие определяет допустимость последующих переходов: D_t → T_t → D_{t+1} (модель D v0.5).

О4. **Преобразование** (оператор 𝒯): 𝒯_Ξ(·) — обновление условий: новые T_{n+1}, расширение языка Σ_{n+1} ⊇ Σ_n (мета-переход допущен: v0.6 тест 4, S2-b), формирование новых полей возможностей. Преобразование меняет не только конфигурации, но и пространство возможного — это разные вещи по v0.6 (строка 1240).

О5. **Соединение без слияния** ⊔: Ξ ⊔ Ξ′ — монотонное расширение, Ξ ↪ Ξ″; ничего не удаляется и не отождествляется. Возникшее не отменяется (А5), различия сохраняются (А3).

О6. **Несводимость триады**: 𝒱 ⊥ 𝒲 ⊥ 𝒯 — попарная невыводимость операторов. Доказательная база: v0.5 (E ⇏ ΔD, D ⇏ E) и S2–S4 (новизна элемента ≠ новизна способа порождения ≠ новизна пространства возможностей). Именно О6 запрещает слить триаду в один гомогенный оператор — это математическая запись А3.

## 4. Вывод единой формулы (5 шагов)

- Ш1 (А2 + строка 219): симметричные стрелки «↔» заменяются на асимметричную композицию с обратной связью: возникновение → взаимодействие → преобразование → (новые условия) → … Это даёт порядок операторов 𝒯 ∘ 𝒲 ∘ 𝒱.
- Ш2 (А4 + О2): возникновение = переход с фильтром структурной новизны ≇_Σ.
- Ш3 (А5 + О5): память реализуется как монотонность: Ξ_n ↪ Ξ_{n+1}; новое достраивает старое, ничего не стирая. Аргумент H из S(n+1)=F(S,R,H) поглощён состоянием Ξ.
- Ш4 (А3 + О6): три оператора входят в одну формулу, но остаются несводимыми — единство без унификации.
- Ш5 (S1–S5): Ξ_0 — граничное условие, не выводимое формулой;claim абсолютного генезиса запрещён строкой 6226.

## 5. ЕДИНАЯ ФОРМУЛА

**Ξ_{n+1} = Ξ_n ⊔ 𝒯 ∘ 𝒲 ∘ 𝒱 (Ξ_n), при 𝒱 ⊥ 𝒲 ⊥ 𝒯, n = 0, 1, 2, …**

Развёрнутая запись (всё в одной строке):

**Ξ_{n+1} = Ξ_n ⊔ 𝒯_{Ξ_n} ( 𝒲_{Ξ_n} ( { (c, c′) ∈ T_n : c′ ≇_{Σ_n} c } ) )**

Чтение: следующее состояние генезиса есть прежнее состояние, достроенное (⊔, без слияния) преобразованием (𝒯) результатов взаимодействия (𝒲) тех переходов, что породили структурно новое (𝒱). Это математическая запись вербальной формулы трактата «Существовать — значит возникать в отношениях, сохранять определённость во взаимодействии и становиться условием дальнейших изменений» (строки 337–343) и формулы строки 265.

## 6. Свойства формулы = «единство без унификации»

- С1 Единство: одна формула описывает весь такт генезиса — триада сочленена в один процесс.
- С2 Без унификации: операторы попарно несводимы (О6); шаг инъективен (О5) — различия не отождествляются.
- С3 Без цели: неподвижная точка не постулируется, формула не «стремится» к финалу; терминалы не привилегированы (И4 артефакта: «НАПРАВЛЕННОСТЬ — НЕ ПРОГРЕСС»; примечание к deepest path v0.10: конец цепи — равноправный терминал, не «итог развития»). А6 выполнен: ни один участник не исчерпывается функцией в другом.
- С4 Честность: формула описывает становление от данного Ξ_0; «творение из ничего» она не выражает и не должна (строка 6226).
